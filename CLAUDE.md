# Grantchi

Агрегатор возможностей для молодёжи Узбекистана. Концепт и стек — [README.md](README.md), архитектура — [docs/architecture.md](docs/architecture.md), источники — [docs/sources.md](docs/sources.md). Интерфейс и контент — только на узбекском.

## Бесплатный тариф Cloudflare

Лимиты общие на весь аккаунт и делятся между 5 проектами (Rida, Zumda, ilk•ish, Uyim, Grantchi). Бюджет Grantchi: до 5000 запросов к Worker в сутки, до 1 млн прочитанных строк D1 в сутки, до 1 ГБ в R2, ровно 1 cron. На один вызов: 10 мс CPU, 50 внешних запросов, 50 запросов к D1.

Правила:

- **Файлы не через Worker.** Статика — из Pages, открытый каталог — готовым JSON. Через Worker идут только закрытые файлы после проверки прав.
- **API на том же адресе**, что Mini App: `grantchi.uz/api/*`, без CORS.
- **Один cron.** Новая периодическая задача — ветка по времени внутри `scheduled()`, а не новый cron. Тяжёлое (сбор, разбор, AI) — в GitHub Actions.
- **Индекс на каждый WHERE и ORDER BY.** Новый запрос к D1 — сразу проверить, что есть подходящий (составной) индекс. Пагинация курсором, без `OFFSET`.
- **Без `COUNT(*)` на каждой странице.** Счётчики — хранимые или приблизительные.
- **Опрос не чаще раза в 30 с** из Mini App и бота.
- **Срок жизни файлов в R2**: на каждый бакет правило жизненного цикла.
- **`workers_dev = false` и WAF**: Worker доступен только через grantchi.uz, на `/api/*` правило ограничения частоты.
- **Логи 20%**: `head_sampling_rate = 0.2` в observability.
- **Внешние запросы считать**: не больше 50 за вызов, рассылки — пачками по 40.
- **Платное — нельзя.** Только бесплатные тарифы; домен уже куплен.

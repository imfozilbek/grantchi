# Сборщик возможностей

Забирает новые записи из источников, отдаёт их AI-пулу, который пишет карточку на узбекском, и отправляет черновики на модерацию. Запускается в GitHub Actions каждые 6 часов (`.github/workflows/collect.yml`), лимиты Cloudflare не тратит.

## Как работает

1. **Источники** — `src/sources.ts`, стартовые 13 из топ-10 в [docs/sources.md](../docs/sources.md). У каждого своя частота (`everyHours`): ежедневные агрегаторы — раз в 6 часов, официальные программы — раз в 3 дня.
2. **Разбор:** RSS/Atom, публичная страница Telegram-канала (`t.me/s/<канал>`), Devpost API. Для RSS, где в ленте только отрывок, скачивается полный текст статьи.
3. **Отбор:** пропускаются уже обработанные записи и записи старше 45 дней. За один запуск — не больше 25 записей, поровну из разных источников, чтобы беречь бесплатные квоты.
4. **AI-пул** (`src/ai/`): первый провайдер с ключом; при 429 или ошибке ключа он выбывает до конца запуска, при плохом ответе запрос уходит следующему. Модель пишет карточку на узбекском (латиница) только по фактам из текста и отсеивает новости и отчёты.
5. **Проверка:** ответ проверяется по схеме (`src/types.ts`). Карточки с прошедшим дедлайном отбрасываются. Остальные получают пометки для модератора: нет дедлайна, нет официальной ссылки, непонятно, могут ли подать граждане Узбекистана, низкая уверенность модели.
6. **Доставка:** если задан `GRANTCHI_API_URL`, черновики уходят в `/api/internal/drafts` пачками по 20. Пока Worker не готов, они сохраняются в артефакт запуска на 14 дней.

Запись помечается обработанной только после успешной доставки. Если квоты кончились, необработанные записи повторятся в следующий запуск.

## Настройка

Ключи AI задаются в Settings → Secrets and variables → Actions репозитория. Нужен хотя бы один.

| Секрет | Провайдер |
| --- | --- |
| `GEMINI_API_KEY` | Google Gemini |
| `GROQ_API_KEY` | Groq |
| `CEREBRAS_API_KEY` | Cerebras |
| `MISTRAL_API_KEY` | Mistral |
| `GH_MODELS_TOKEN` | GitHub Models (токен с правом `models:read`) |
| `OPENROUTER_API_KEY` | OpenRouter |
| `CLOUDFLARE_AI_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` | Workers AI, всегда последний: квота общая на 5 проектов |

Модель любого провайдера меняется переменной `<ID>_MODEL`, например `GROQ_MODEL`. Порядок пула — `AI_PROVIDERS=groq,gemini`.

Позже: `GRANTCHI_API_URL` (переменная) и `GRANTCHI_INGEST_SECRET` (секрет), когда появится Worker.

## Локальный запуск

```sh
npm ci
npm test
FORCE=1 npm run collect                      # без ключей: только сбор, записи в out/pending-*.json
GROQ_API_KEY=... FORCE=1 MAX_ITEMS=5 npm run collect
SOURCES=grantlar,devpost FORCE=1 npm run collect
```

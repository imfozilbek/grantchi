# Grantchi

Сайт: [grantchi.uz](https://grantchi.uz)

Агрегатор возможностей: стипендии, гранты, конкурсы и программы в одном месте, плюс помощь с подачей заявки.

## Для кого

На старте — студенты и молодёжь Узбекистана. Дальше — СНГ.

## Главный принцип

**Freemium: часть контента бесплатно, полный доступ — по подписке.** Сверху — разовые платные услуги по заявкам.

## Бесплатно

- Ограниченная часть возможностей (в канале и в боте)
- Статьи: как выиграть стипендию, разборы успешных заявок

## Подписка

- Вся база возможностей с фильтрами: страна, уровень, сфера, дедлайн
- Новые возможности сразу (бесплатно — с задержкой или частично)
- Подбор под профиль
- Напоминания о дедлайнах
- Чек-листы документов по каждой программе

## Разовые услуги

- Проверка мотивационного письма / эссе
- AI-помощник для письма
- Полное сопровождение заявки
- Консультация

## От организаций

- Комиссия от вузов и агентств за приведённого студента
- Реклама языковых школ и IELTS-центров
- Платное размещение программ от вузов и грантодателей

## Каналы

Telegram-канал, Telegram-бот, мини-апп в Telegram, веб-приложение.

## Отличие от конкурентов

Не просто список возможностей, а путь до поданной заявки: подбор → чек-лист → напоминания → помощь с документами.

## Версия 1

Язык: только узбекский.

| Канал | Роль |
| --- | --- |
| Telegram-канал | Бесплатная воронка: 2–3 возможности в неделю, статьи, ссылка на бота |
| Telegram-бот | Знакомство (уровень, сфера, страны), уведомления и напоминания о дедлайнах, предложение подписки |
| Мини-апп | Каталог возможностей: карточки, фильтры, подбор под профиль, чек-листы, сохранённые программы |

Бесплатный пользователь видит ограниченную подборку, новые программы с задержкой 7 дней и закрытые детали. Подписка (для теста ~$3/мес) открывает всё. Открытый вопрос — оплата подписки: решить позже; внутри Telegram цифровое продаётся только за Stars.

Работу с контентом делают AI-модели:

- **Сбор возможностей:** модель читает сайты программ и официальные источники, вытаскивает поля (страна, уровень, финансирование, дедлайн, требования, документы, ссылка), пишет карточку и чек-лист на узбекском. Человек-модератор одобряет карточку перед публикацией.
- **Проверка актуальности:** модель регулярно перепроверяет дедлайны и ссылки, помечает устаревшие программы.
- **Посты для канала:** модель готовит черновики, человек публикует.

Не входит в версию 1: сайт, проверка эссе и другие разовые услуги, трекер заявок.

Источники возможностей: [docs/sources.md](docs/sources.md).

## Стек

Всё на бесплатных тарифах, домен grantchi.uz уже куплен. Лимиты Cloudflare общие на аккаунт и делятся между 5 проектами — бюджет Grantchi и решения в [docs/architecture.md](docs/architecture.md).

| Часть | Сервис |
| --- | --- |
| Mini App, админка (`/admin`) и API (`/api/*`) | один проект Cloudflare Pages + Functions, один адрес grantchi.uz, без CORS |
| Telegram-бот (webhook) | тот же Worker/Functions |
| База данных | Cloudflare D1 |
| Файлы | Cloudflare R2, закрытый бакет, выдача только через Worker после проверки прав |
| Расписание | ровно 1 cron в Cloudflare; задачи выбираются по времени внутри `scheduled()` |
| Сбор источников и AI-обработка | GitHub Actions по расписанию; черновики карточек отправляются в Worker по секрету |
| Доступ к админке | Cloudflare Access |
| AI-модели | Пул бесплатных квот крупных провайдеров (см. ниже) |

Supabase не нужен, пока хватает Cloudflare.

## AI: пул бесплатных квот

Используем бесплатные тарифы нескольких провайдеров (например, Google Gemini, Groq, Mistral, OpenRouter, Cerebras, GitHub Models, Cloudflare Workers AI). Список расширяемый.

- Один общий интерфейс для всех провайдеров.
- Роутер: берёт первого подходящего провайдера под задачу; при ошибке лимита (429) или сбое переключается на следующего.
- Учёт расхода квот: одна строка на (провайдер, день), не строка на вызов.
- Cloudflare Workers AI — последним в очереди провайдеров: его квота общая на 5 проектов.
- Задачи делятся по качеству: сбор карточек — любые модели; проверка эссе — только лучшие из пула.
- Эссе — личные данные пользователя: отправляем их только провайдерам, которые не обучают модели на данных бесплатного тарифа.
- По одному аккаунту на провайдера: несколько аккаунтов ради обхода лимитов нарушают условия и ведут к блокировке.

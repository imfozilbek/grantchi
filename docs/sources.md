# Источники возможностей

Черновой список. Проверить каждый: есть ли RSS или API, как часто обновляется, что разрешают условия сайта.

## Правила

- **Официальный сайт программы — источник правды.** Дедлайн, требования и документы сверяем с ним.
- **Агрегаторы — для поиска новых возможностей**, не для копирования. Факты (название, дедлайн, требования) берём, текст пишем свой на узбекском, в карточке всегда ссылка на официальный сайт.
- **Узбекские каналы-конкуренты** — только для мониторинга: что уже публикуют и что пропустили.
- Сначала RSS или API, потом парсинг страниц. Уважаем robots.txt и условия сайтов.
